# Number Guessing Game

## Project Overview

Number Guessing Game is a Java-based console application where the player tries to guess a randomly generated number within a limited number of attempts.

## Features

* Random number generation
* Three difficulty levels:

  * Easy: 1–50, 10 attempts
  * Medium: 1–100, 7 attempts
  * Hard: 1–200, 5 attempts
* Too High / Too Low hints
* Attempt counter
* Multiple rounds
* Score tracking
* Play Again option
* Final game summary

## Technologies Used

* Java
* Random
* Scanner
* Loops
* If-Else
* Boolean variables

## How to Run

1. Open the project in VS Code.
2. Compile the Java file.
3. Run the program.
4. Select a difficulty level.
5. Enter guesses according to the instructions.
6. Choose whether to play another round.
